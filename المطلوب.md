### Project Overview
You will build a **University Orientation System** that recommends majors (e.g., AI, Software Engineering, Cybersecurity) to students based on their grades, skills, and interests. The core objective is to implement and compare three different AI reasoning methods covered in your syllabus.

### Step-by-Step Tasks

**1. Knowledge Modeling**
*   Select 3 university majors and define admission/orientation criteria.
*   Create **10 diverse student profiles** (mock data).
*   Define the base facts and rules for the system.

**2. Classical Logic (Propositional/Predicate Logic)**
*   *Syllabus Link: Chapitre I, A (Logique Classique)*
*   Write strict True/False rules to determine if a student is eligible for or recommended a major.
*   Implement the deduction engine in Python and test it on the 10 profiles.

**3. Default Logic (Non-Monotonic Reasoning)**
*   *Syllabus Link: Chapitre I, B.2 (Logique des défauts)*
*   Write at least **4 default rules** (e.g., "Assume a student is suited for AI *unless* we have data proving otherwise").
*   Implement at least **1 exception** that forces the system to retract a previous assumption.
*   Compare how these flexible conclusions differ from the strict Classical Logic results.

**4. Fuzzy Logic**
*   *Syllabus Link: Chapitre III (Théorie des sous-ensembles flous)*
*   Define input variables (e.g., Algorithm skill, Programming skill, Interest) and an output variable (Suitability Score).
*   Create membership functions (e.g., Low, Medium, High) instead of strict True/False.
*   Write at least **6 fuzzy rules** (e.g., "IF Algorithm is High AND Interest is Medium THEN Suitability is High").
*   Calculate exact suitability percentages for the profiles.

**5. Comparative Analysis**
*   Compare the three methods based on:
    *   How they handle missing data and exceptions.
    *   How they handle imprecise information (fuzzy vs. crisp).
    *   Pros and cons of each approach.

### Deliverables
1.  **Report:** Maximum 6 pages covering your models, logic, test results, and comparative analysis.
2.  **Code Package:** Python scripts, facts/rules databases, student profiles, and output logs. All conclusions must be justified by the code/data during your validation session.
